How I make AI available to everyone

Four steps I follow each time.

  1. Find the repeat

    Look for the checks and decisions people make over and over.

  2. Prototype on real data

    Build a working version fast and test it on real drawings and packages.

  3. Make it easy to use

    Put it inside the tools people already use, so nobody needs to be an AI expert.

  4. Train, measure, improve

    Teach it to everyone, check who really uses it, and keep improving it with their feedback.
