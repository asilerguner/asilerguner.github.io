ComplianceWorks

SolidWorks Add-in · VB.NET · CAD Standards Automation

An enterprise SolidWorks add-in that lets a company enforce its own CAD standards across every engineer, from one central control panel. Admins define design guidelines and rules once, export them as a JSON configuration, and every user's add-in syncs to it automatically - no reinstalling, no manual rollout. Ships with a large utility toolkit (Quick Check, feature tree organizer, dangling dimension cleanup, missing reference finder, QR code generator, configuration splitter, and more), integrated news/push notifications, centralized document resources, and support for running company-defined macros directly from the task pane.

  • Centralized rule management
  • Live JSON-based sync
  • 14 built-in utilities
  • Custom macro runner
