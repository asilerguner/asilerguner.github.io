About SimPallet

SimPallet

Version 2026.1

SimPallet plans and visualizes pallet, case, and truck loading in 3D - build a pallet, create a case, fill a stock case, resize a primary pack, palletize knocked-down flats, and load multi-sized products, all with an interactive 3D preview and a shareable PDF report.

General Settings

This app's own feature, no CapePack equivalent. Optional — leave blank to hide the estimate. Multiplies your own gross load weight (product + case + pallet) by the factors below.

Edge Crush Formulae

Single Wall:
ECT = (((Medium Factor 1 x Takeup Factor 1) + Σ(Liner Factors) ) x 0.642 ) + 0.948

Double Wall:
ECT = ((Medium Factor 1 x Takeup Factor 1) + (Medium Factor 2 x Takeup Factor 2) + Σ(Liner Factors) x 0.473 ) + 24.853

Triple Wall:
ECT = 1.28 x ((Liner 1 + (Flute 1 x Medium 1) + Liner 2 + (Flute 2 x Medium 2) + Liner 3 + (Flute 3 x Medium 3) + Liner 4))
